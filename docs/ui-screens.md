## Navigation Flow

```
┌─────────────────────────────────────────────────────────────────────────┐
│                            Navigation Map                                │
└─────────────────────────────────────────────────────────────────────────┘

                              ┌──────────┐

                                   │

                         ┌─────────────────┐

   ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐      │
   │ sing-box │ │   User   │ │  Config  │ │ Settings │      │
   │  Manage  │ │  Manage  │ │   Gen    │ │          │      │
   └────┬─────┘ └────┬─────┘ └────┬─────┘ └────┬─────┘      │
```
